在上一个练习里，你学会了如何读取 `filename` 参数，也就是 `execve` 系统调用中的 `ctx->args[0]`。

现在来看看第二个参数：`argv`。当你运行这样的命令时：
```bash
./secret_app --password hunter2
```

内核收到的是一个参数数组：
- `argv[0]` = `"./secret_app"`
- `argv[1]` = `"--password"`
- `argv[2]` = `"hunter2"`
- `argv[3]` = `NULL`（结束标记）

看看 [execve 手册页](https://man7.org/linux/man-pages/man2/execve.2.html)：

```c
int execve(const char *filename, char *const argv[], char *const envp[]);
```

第二个参数 `argv` 位于 `ctx->args[1]`。

`filename` 是一个指向字符串的简单指针，而 `argv` 和 `envp` 则是**指向指针数组的指针**。

正如你在示意图中看到的，`argv` 和 `envp` 都以一个 NULL 指针结尾。

当你从 `argv` 数组中读取某一项（例如 `argv[i]`）时，使用前要先检查它是否为 `NULL`，因为这标志着数组的结束。

## 读取指针数组

要读取 `argv`，我们需要：

1. 从 `ctx->args[1]` 拿到 argv 指针
2. 把它从 `unsigned long` 转换成 `char **`
3. 逐个读取数组中的指针（从**用户空间**）
4. 对每个指针，读取它所指向的字符串（同样从**用户空间**）

基本结构如下：

```c
// Get the argv pointer
char **argv = (char **)ctx->args[1];

// In a loop, read the next pointer from the array
char *arg_ptr;
bpf_probe_read_user(&arg_ptr, sizeof(arg_ptr), &argv[i]);
// Remember to check for the NULL terminator!

// Read the string that pointer points to
char arg_buf[64];
bpf_probe_read_user_str(arg_buf, sizeof(arg_buf), arg_ptr);
```

记住，循环必须有固定的上界（例如 `i < 10`），因为验证器需要证明你的程序会终止。

## 挑战

有一个可疑的程序正在被执行，它带了一个 `--password` 标志，后面跟着真正的密码。

你需要：

1. 遍历 `argv` 数组（迭代上限设为 10 个参数）
2. 找到包含 `"--password"` 的那个参数
3. 读取**下一个**参数，里面是真正的密码
4. 用 `SUBMIT_STR_LEN` 提交它
