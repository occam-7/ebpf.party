和 `open()`、`read()` 一样，网络连接也有发起（entry）和结果（exit）两个阶段。要关联这两个事件，我们在 entry 存数据，在 exit 取回来。

## connect 系统调用

```c
int connect(int sockfd, const struct sockaddr *addr, socklen_t addrlen);
```

在 **entry**（`sys_enter_connect`）处：
- `ctx->args[0]` = socket 文件描述符
- `ctx->args[1]` = 指向 `sockaddr` 结构体的指针（用户空间）

在 **exit**（`sys_exit_connect`）处：
- `ctx->ret == 0` → 连接成功
- `ctx->ret < 0` → 连接失败（errno 值）

## 读取 sockaddr 结构体

`addr` 指针（位于 `ctx->args[1]`）指向用户空间内存。必须用 `bpf_probe_read_user()` 才能安全地拷贝它：

```c
struct sockaddr_in addr;
bpf_probe_read_user(&addr, sizeof(addr), (void *)ctx->args[1]);
```

对于 IPv4 连接（`sin_family == 2`）：

```c
struct sockaddr_in {
    u16 sin_family;  // AF_INET = 2
    u16 sin_port;    // Port (network byte order!)
    u32 sin_addr;    // IP address
    char __pad[8];
};
```

端口和 IP 采用**网络字节序**（[大端](https://en.wikipedia.org/wiki/Endianness)）。用辅助函数转换成本机字节序：

```c
u16 port = bpf_ntohs(addr.sin_port);
```
