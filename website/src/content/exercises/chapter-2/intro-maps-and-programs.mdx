到目前为止，每个练习都只用了单个 eBPF 程序。但如果我们需要把不同事件中的信息关联起来呢？

举例来说：当一个进程**启动**时，我们知道它的名字；当它**退出**时，我们知道它的退出码。如果想查出以某个特定退出码退出的进程的**名字**，该怎么办？

## 多个 eBPF 程序

你可以在**一个文件里定义多个程序**，每个程序挂载到不同的事件上。

每个程序相互独立，在各自的事件触发时运行。

最常见的需要多个程序的场景，就是 `entry`+`exit` 这样成对的事件。

在 **entry** 处，我们拿到的是输入（参数、进程信息）。

```c
SEC("tracepoint/sched/sched_process_exec")
int on_process_start(struct trace_event_raw_sched_process_exec *ctx) {
    // When the process starts execution
}
```

在 **exit** 处，我们拿到的是输出（返回值、退出码）。

```c
SEC("tracepoint/syscalls/sys_enter_exit")
int on_process_exit(struct trace_event_raw_sys_enter *ctx) {
    // When the process calls exit (program termination)
    // ctx->args[0] contains the exit code
}
```

要关联这两个事件，我们需要在两次程序调用之间把数据保存下来。

## 保存状态

**Map** 是一种在 eBPF 程序多次调用之间持续存在的数据结构。

eBPF 里有[很多种](https://docs.ebpf.io/linux/map-type/) map。这个练习里我们使用哈希 map（键值存储）。

map 的用法很直接。首先用这些 `__uint`/`__type` 宏声明一个结构体。

```c
struct {
    __uint(type, BPF_MAP_TYPE_HASH);
    __uint(max_entries, 1024);
    __type(key, u64);         // What you use to look up
    __type(value, char[16]);  // What you store
} my_map SEC(".maps");
```

存数据时，你传入一个指向数据的指针，数据会被拷贝进去：
```c
u64 key = 12345;
char value[16] = "hello";
bpf_map_update_elem(&my_map, &key, value, BPF_ANY);
```

要取回指向值的指针：
```c
char *stored = bpf_map_lookup_elem(&my_map, &key);
if (!stored) { // Key not found
    return 0;
}
// Use `stored` (it's a pointer to the char[16] array)
```

从 map 中删除一个条目：
```c
bpf_map_delete_elem(&my_map, &key);
```
