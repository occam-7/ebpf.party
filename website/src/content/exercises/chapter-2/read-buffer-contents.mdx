上一个练习里，我们学会了用 map 在多个 eBPF 程序之间共享数据。

现在我们把这个方法用到从系统调用缓冲区中捕获数据上。系统调用有两个挂载点事件：`enter`（调用开始前）和 `exit`（调用结束后）。我们需要在两者之间关联数据。

## read 系统调用

看一下 [read 系统调用](https://man7.org/linux/man-pages/man2/read.2.html)：

```c
ssize_t read(int fd, void *buf, size_t count);
```

如果我们挂载到 `sys_enter_read` 和 `sys_exit_read` 上：

- 在 **entry**：可以访问到参数，但缓冲区还是空的。
- 在 **exit**：缓冲区里已经有数据了，但我们只能访问到返回值。

为了把两者串起来，我们在 entry 处用 map 记下缓冲区指针，然后在 exit 处读取填好数据的缓冲区。

## 在 entry 处保存缓冲区地址

首先，我们需要在系统调用开始时把缓冲区指针存下来。缓冲区地址在 `ctx->args[1]` 里。

我们把这个地址存进 map，用 PID 作 key，这样后面还能查回来：

```c
u64 buf_addr = ctx->args[1];
bpf_map_update_elem(&read_buffers, &pid, &buf_addr, BPF_ANY);
```

注意，我们存的是缓冲区的地址，类型是 `u64`。

## 在 exit 处读取缓冲区

现在在 exit 程序里，我们要取出并读取被系统调用填好的缓冲区。

首先检查读取是否成功：

```c
size_t count = ctx->ret;
if (count <= 0) return 0;
```
返回值 `ctx->ret` 告诉你读到了多少字节。

接下来，用 PID 作 key 查出之前保存的缓冲区地址：
```c
u64 *buf_ptr = bpf_map_lookup_elem(&read_buffers, &pid);
if (!buf_ptr) return 0;
```
返回的是指向所存值的指针（`u64*`）。

要读取缓冲区，先创建一个本地缓冲区，再用 `bpf_probe_read_user`。你需要解引用 buf_ptr 才能拿到真正的缓冲区地址：

```c
char local_buf[32];
if (count > 32) count = 32;
bpf_probe_read_user(local_buf, count, (void *)*buf_ptr);
```
注意 `*buf_ptr` —— 这里解引用指针，取出我们之前保存的缓冲区地址。
