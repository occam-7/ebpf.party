我们已经从系统调用缓冲区里读过文件内容了。现在我们来读网络数据 —— 具体地说，是 DNS 响应，从中提取 IP 地址。

## recvfrom 系统调用

DNS 客户端用 `recvfrom()` 接收 UDP 响应：

```c
ssize_t recvfrom(int sockfd, void *buf, size_t len, int flags,
                 struct sockaddr *src_addr, socklen_t *addrlen);
```

和 `read()` 一样，我们需要把进入和退出关联起来：
- 在 **entry** 时：缓冲区还是空的，但我们可以从 `ctx->args[1]` 拿到指针
- 在 **exit** 时：缓冲区里已经填好了 DNS 响应，`ctx->ret` = 收到的字节数

## DNS 报文结构

```c
struct dns_header {
    u16 id;
    u16 flags;
    u16 qdcount;   // Question count
    u16 ancount;   // Answer count
    u16 nscount;
    u16 arcount;
};
```

头部之后是：**Question section**（域名）→ **Answer section**（IP 地址）。

### 域名的编码方式

DNS 把域名编码成带长度前缀的 label：`\x04ebpf\x05party\x00` 表示 "ebpf.party"。

解析方法：
```c
int pos = sizeof(struct dns_header);
char domain[64];
int out = 0;

#pragma unroll
for (int i = 0; i < 10; i++) {  // Max 10 labels
    u8 len = buf[pos++];
    if (len == 0) break;

    #pragma unroll
    for (int j = 0; j < 63; j++) {
        if (j >= len) break;
        domain[out++] = buf[pos++];
    }

    if (buf[pos] != 0) domain[out++] = '.';
}
```

### Answer section 的结构

在 question（域名 + QTYPE + QCLASS）之后，answer 里包含：

```c
// NAME (variable, often a pointer)
// TYPE (2 bytes) - 0x0001 for A record (IPv4)
// CLASS (2 bytes)
// TTL (4 bytes)
// RDLENGTH (2 bytes) - should be 4 for IPv4
// RDATA (4 bytes) - the IP address
```

对于 A 记录，RDATA 就是网络字节序的 IPv4 地址。

## 挑战

某个程序会发起 DNS 查询。找到 "ebpf.party" 的响应，提交它的 IP 地址。

在 `recvfrom` 的 entry 处保存缓冲区指针。在 exit 处读取 DNS 响应，从 question section 解析出域名，用 `bpf_strncmp()` 检查它是否匹配 "ebpf.party"，然后从 answer section 提取 IPv4 地址并提交。

IP 地址是网络字节序的 4 个字节。要得到一个 `u32`，可以用 `bpf_ntohl()` 转换，再用 `SUBMIT_NUM()` 提交。
